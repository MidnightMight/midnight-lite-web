Rebuilding this website (again)

16 Oct 2026 · 5 min read · by @midnightlite

A1 post header. This is now your first real post, documenting the redesign (your note on the decisions page). Wording is a draft in your voice; mark up anything that doesn't sound like you.

The first version of this site was hand-written HTML and CSS: a few coding projects mashed together, a carousel on the home page, and a "Services" page that was really just a launcher for my own web apps. Later a GitHub bot helped me clean it up a lot. It worked, but it was built for showing a CV, not for what I actually want to do now: make videos, write up builds, and share the whole process.

So I'm rebuilding it around three things: projects, videos and build logs. Here's what changed and why.

What moved where

Decisions I made

  • Built with Astro. Posts and projects are now Markdown files instead of hand-written HTML pages, so writing a new post takes minutes. It still produces plain, fast pages on Netlify.
  • Comments live on YouTube. No comment system on the site to moderate or keep running. Ask under the video and I'll answer there.
  • A newsletter. New videos and build logs about twice a month, by email. No spam.
  • Faceless for now. I'm @midnightlite, and the hexagon logo does the talking.
  • Fewer, better projects. I start with three: the ferrofluid display, the EUC visualiser and this website. More get added as they become worth showing.
Before / after screenshot of the home page

How I'm building it

The layout started as a clickable prototype that I printed, scribbled on and sent back (the headline you see on the home page came from that round). The source lives on GitHub and is backed up to my own Git server at home, and every change goes to a preview branch before it reaches the live site.

Lesson so far: printing a design and attacking it with a pen finds problems much faster than staring at it on a screen.

What's next
