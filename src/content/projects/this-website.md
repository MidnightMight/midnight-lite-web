## Why I built it

A personal hub for showcasing side projects, tools and experiments, built from scratch so it loads fast and the source stays easy to read. The site is both the product and the live documentation of its own creation.

## How it works

The 2026 version is built with **Astro**: projects, posts and videos are Markdown files, and Astro turns them into plain, fast HTML pages. Interactive tools like the EUC visualiser are small React apps that only load on their own page. Cloudflare serves the site and redeploys it automatically from GitHub.

I edit content through a small admin editor in the browser, which saves straight to the GitHub repo.
